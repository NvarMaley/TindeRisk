# GitHub Infrastructure

The shared repository is https://github.com/NvarMaley/TindeRisk.git.
V3 replaces the V2 working tree in a normal commit and retains the existing
Git history. Repository membership and protection settings are managed by the owner.

Use feature branches, reviewed pull requests and green CI. Collaborators install
the locked environment using INSTALL.command and provision licensed data using
their own authorized access. Keep private data and credentials out of Git.
See CONTRIBUTING.md and notebooks/README.md.
