# Local V3 Web App

Served by the local API at http://127.0.0.1:3000.
Mandate → Discovery → Explore → comparison. Synthetic, unvalidated results.

The V2 visual identity is retained: lagoon at dusk (desktop/mobile), cherry crest, pink/blue wordmark, Archivo Black/DM Sans and original jazz. Clicking Press to start or pressing Enter begins the five-second opening animation and music; the intro cannot be skipped. Music remains controllable. After opening, unlock an existing save with its four-digit PIN or create a new save using only a name and four-digit PIN. Entering without a save is disabled. Navigation is shown only while a save is unlocked. Each save is independent; changes are saved automatically and can also be saved or locked from Saves. Previous passphrase-based saves remain accessible using their original credential. Browser-local simulation only, no real personal data or online account.

English is the canonical project language. Use the English/Français selector to switch all visible UI without clearing simulation state. Quantitative logic and checklist remain V3.

Chapter 01 provides the USD client form, with dates, capital, cash flows, ten goals and risk limits. Optional balance-sheet details and advanced limits are collapsed. Income is defined by withdrawals, and inflation and scenario FX appear when needed. Load a fictional example, preview calculations, revise conflicts, then explicitly confirm. Confirmation replaces the portfolio deck and can carry Discovery answers forward if the currency is unchanged. See `docs/CLIENT_MANDATE.md` for current form and legacy schema behavior.

Chapter 02 uses the same 30 bilingual questions, in the same order, in every session. Yes accepts the proposed switch and No keeps the starting option. Touch, keyboard, unsure, skip and undo are available. The 1–30 prudence index requires 14 out of 20 scored items. The eight mixed gain/loss choices feed threshold ranges under four assumptions, while two cards check comprehension and consistency. The portfolio risk coefficient is `1 + 13.3 q²`. Saved answers from retired questionnaires restart on the fixed questionnaire.

The client Universe tab lists the US stocks, equity ETFs, US Treasury ETFs and USD cash used by the personalized portfolio engine. The engine counts the assets from the 60-month eligibility window ending 31 December 2025. Sources explains missing data, remaining biases and the archived audits. Chapter experiments remain in the notebook and shared research code. See `docs/PERSONALIZED_MATCHING.md`.
