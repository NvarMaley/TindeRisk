# Local V3 Web App

Served by the local API at http://127.0.0.1:3000.
Mandate → Discovery → Explore → comparison. Synthetic, unvalidated results.

The V2 visual identity is retained: lagoon at dusk (desktop/mobile), cherry crest, pink/blue wordmark, Archivo Black/DM Sans and original jazz. Clicking Press to start or pressing Enter begins the five-second opening animation and music; the intro cannot be skipped. Music remains controllable. After opening, unlock an existing save with its four-digit PIN or create a new save using only a name and four-digit PIN. Entering without a save is disabled. Navigation is shown only while a save is unlocked. Each save is independent; changes are saved automatically and can also be saved or locked from Saves. Previous passphrase-based saves remain accessible using their original credential. Browser-local simulation only, no real personal data or online account.

English is the canonical project language. Use the English/Français selector to switch all visible UI without clearing simulation state. Quantitative logic and checklist remain V3.

Chapter 01 provides the complete local mandate form (reference currency, balance sheet, cash flows, goals, loss capacity, experience, restrictions, review). Load a fictional example, preview calculations, revise conflicts, then explicitly confirm. A new confirmed mandate resets discovery and portfolio choices; the existing local save is isolated. The legacy USD synthetic Explore demo is blocked for CHF and other unmodeled hard constraints. It never evaluates complete suitability. See `docs/CLIENT_MANDATE.md`.

Chapter 02 now uses a versioned 60-card bank and balanced randomized 30-card sessions. Separate consent, session seed/version and response locale are stored only in the current local save. Each card presents both choices in one question. Yes (right) accepts the proposed switch and No (left) keeps the starting option. Touch, keyboard, buttons, unsure, skip and undo are available; withdraw/reset independently of the mandate. The experimental 1–30 score requires at least 14/20 scored items and reports coverage, sensitivity, pair differences and separate preferences. Existing partially answered legacy sessions retain their original deck. No human study, clinical diagnosis or suitability assessment.

Chapter 03 adds a read-only Universe tab for 22 ETF research candidates, distinct from USD cash and the DTB3 rate proxy. It shows issuer facts, filters, local observed or reported coverage and eligibility blockers, never promotes a fund on the basis of ticker/price availability. The Treasury-only rule requires verified point-in-time holdings; actual investability remains gated pending data validation.
