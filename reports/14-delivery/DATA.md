# Delivery register

## What a public checkout can reproduce

A public checkout contains the Python and Streamlit code, the simulated cases and fill tape algorithm, dated model parameters, published research tables, notebook outputs and figures. It can rerun the end-to-end application and recompute the release comparisons without a data account. The Git inventory records every shipped file and hashes key inputs. A fresh fit from individual security histories requires the private sources listed below. [Tracked files](public-files.json) · [Model and simulation](../13-application/README.md)

## Audit boundary

The inventory checks the Git-tracked release, enforces explicit categories for raw-data file types and the four shipped CSVs, and detects public-input changes by digest. The section 13 privacy replay separately tests cross-account access, deletion, and three private fixture markers. These checks cover this distribution. Separate market data agreements would be needed to operate and distribute a live portfolio price service.
