# Optional StockTwits sentiment — historical research (chapters 8, 10, 15)

The course archive contains 6,773,807 firm/day records, 8,843 tags, roughly 90.9m total messages, July 2009 to 23 March 2020. Use only supplied Parquet, verified against `sentiment_asset_metadata.json` source SHA256, never deserialize unknown pickle files. `N` includes unlabelled messages; labelled = bullish + bearish, so polarity `(bullish-bearish)/(bullish+bearish)` is undefined when no labels, not zero. Labelled share = labelled/N; volume = log(1+N). Daily UTC date, historical CRSP name validity interval and permanent ID join across all active names; ambiguous ticker reuse discarded. Date and source hash of the current names archive verified; no original publication timestamp certification. Course use is local/private; no raw data or derived private results on public GitHub.

Aggregate monthly counts, minimum five labelled messages, no zero-filling; exclude partial first and last archive months. Feature month must be a complete calendar month strictly before the return interval start month, conservative beyond next-session availability. Target is subsequent monthly total return, lagged previous return and trailing three months only as baseline. Same sample by baseline/augmented paired experiment, chronological 60/20/20 by end month, fixed predeclared hyperparameters, standardization fitted before holdout; train+validation used to fit fixed final models. Pooled panel, not replacement of each existing individual asset model. Seven paired regressors OLS/Ridge/Lasso/Elastic Net/Random Forest/XGBoost/MLP; simple historical/rolling3/EWMA references separately (adding a feature changes their definition). Per-asset test metrics shown only with at least five held-out rows, still small samples. Three-calendar-month block bootstrap on equal-month-weight paired squared errors, 1,000 draws; interval is conditional, not proof of causality or multiple-test corrected significance. Data downloaded years later: retrospective only, cohort selection/survivorship bias, no PIT certification.

Historical factor: equal-weight top minus bottom sentiment quintile, minimum 20 simultaneous assets, deterministic ID tie-break, realized next-month return spread and Spearman rank IC. Gross illustrative spread, not a short-enabled, net-funded strategy. Historical scalar BL-style relative-view diagnostic combines same-date ridge baseline predicted spread and augmented spread with fixed 25% view confidence, compares realized spread prediction errors; not the full equilibrium engine or a current view. No current forecast, factor risk estimate, optimizer, or BL view changes from stale sentiments. If a licensed dated live feed becomes available, revalidate identity, availability, calibration and incremental predictive power before switching on any model input.

Local run 2026-11-25: 753 matched assets out of 1,022 monthly return candidates (562/575 common cohort, 22 ETFs), 61,141 asset-months, August 2009–February 2020 features, 26 held-out return months March 2018–April 2020. Five models show small positive point RMSE improvements, RF and XGBoost degrade. All paired block intervals include zero. Held-out mean monthly sentiment spread −0.437%, rank IC −0.0094. BL scalar RMSE 1.3964% → 1.3843%; no promotion.

Build `python scripts/build_sentiment.py --as-of YYYY-MM-DD`, inspect Sources → StockTwits or individual catalogue asset sheet. `/api/sentiment` and `/api/sentiment/asset` serve locally verified aggregate artifacts only. API reports current signal unavailable by design.
